## Jak pracuji

1. **Problém a požadavky.** Jak to dnes funguje, co lidi zdržuje, co má nový nástroj umět.
2. **Stavba s AI.** Kód píše AI, já řídím zadání a rozhoduji o řešení.
3. **Testy.** Pozitivní, negativní a hraniční scénáře. Po každé změně je sám spustí GitHub Actions.
4. **Zavedení.** Krátký návod a zpětná vazba od lidí, kteří to používají.

**Nástroje:** Playwright · GitHub Actions · Jira · SQL (SQLite) · Chrome DevTools · Claude Code · Linux
